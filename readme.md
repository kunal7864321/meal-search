# 🍽 Meal Search App

## 📌 Description
This is a simple web application where users can search for meals and view details like name, category, and instructions. The app uses a public API to fetch real-time data.

---

## 🚀 Features
- Search meals by name  
- Display meal details (image, category, instructions)  
- Responsive design using Tailwind CSS  
- Loading indicator while fetching data  

---

## 🌐 API Used
TheMealDB API  
https://www.themealdb.com/api.php

---

## 🛠 Technologies Used
- HTML  
- Tailwind CSS  
- JavaScript  
- Fetch API
